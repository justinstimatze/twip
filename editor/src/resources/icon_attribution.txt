Third-party artwork still shipped in this tree.

The list this file used to hold covered Wick's icon set — Noun Project and Flaticon drawings
edited by Luca Damasco and Zach Rispoli, across tool-icons/, toolbar-icons/,
asset-library-icons/, interface/, inspector-icons/ and timeline-icons/. Those files were
replaced by twip's own set in src/ui/icon.jsx and deleted, so their attributions no longer
describe anything here. They remain in the git history, and in Wick Editor upstream.
